# Challenge_ClickBus_2025

Projeto BusNext:
O BusNext é um projeto de análise de dados que utiliza dados históricos de clientes para segmentação e previsão da próxima compra.

A solução combina estatística e análise comportamental para identificar padrões de consumo e estimar quando e onde cada cliente tende a realizar uma nova compra.

O objetivo é apoiar estratégias de negócio como:

aumento da conversão de vendas, melhor segmentação de clientes, tomada de decisão baseada em dados, identificação de padrões de comportamento de compra

Tecnologias Utilizadas

Python, Análise Estatística, Jupyter Notebook, Power BI, Análise de Dados

Após baixar o arquivo .zip, é necessário descompactar os arquivos para acessar os materiais do projeto.

O projeto contém:

Arquivo .ipynb
Notebook com as análises de dados, modelagem estatística e previsões realizadas.

Apresentação da solução (PDF)
Slides explicando o problema, metodologia e resultados obtidos.

Dashboard interativo
Visualização dos principais indicadores e insights gerados na análise.
